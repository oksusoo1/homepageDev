1. 인증과 업무 테이블

Supabase Auth가 auth.users를 관리합니다. 비밀번호는 여기에만 저장하고, 앱 테이블은 auth_id로 연결합니다.

auth.users (Supabase 내장) │ ├── auth_id ──► public.customers 고객 (회원가입 시 자동 생성) │ └── auth_id ──► public.staff 본사 직원 (수동 등록)
구분테이블생성 방법로그인 후 화면
고객customers/login 회원가입/my
본사 직원staff NEW대시보드 Add user + SQL INSERT/platform (2단계 코드 연동 예정)

관리자 등록 절차

  1. Supabase 대시보드 → Authentication → Users → Add user
  2. 생성된 사용자의 id(UUID) 확인
  3. SQL Editor에서 실행: 
    INSERT INTO staff (auth_id, email, name, role)
VALUES (
  '여기에-auth-users-id',
  'admin@company.com',
  '관리자',
  'platform_admin'
);

6. PK 명명 규칙

모든 PK는 테이블명_id 형식 (예: customer_id, staff_id, site_id).
sites.site_id = UUID (FK용), sites.site_code = VARCHAR (URL 식별자). 혼용 금지.

7. RLS (현재)

MVP 단계: 모든 테이블 USING (true) — 개발 편의용. 실서비스 전 강화 필요.
