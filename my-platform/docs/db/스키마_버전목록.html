DB 스키마 버전 목록

Supabase(PostgreSQL) 테이블 명세·SQL 스크립트 관리. 스키마가 바뀔 때마다 새 버전 파일을 추가하고, 이 목록을 갱신한다. 이전 버전은 삭제하지 않는다.

v1.0 2026-08-31 이력 staff 테이블 설계·SQL docs 통합 (코드 연동 전) 명세 열기 schema v2.1

버전 추가 규칙

  1. 스키마가 바뀌면 기존 HTML/SQL 파일을 수정하지 않고 새 파일 생성
  2. HTML 명세: 스키마_v{major}.{minor}_{YYYY-MM-DD}.html
  3. 전체 SQL: schema_v{버전}_{YYYY-MM-DD}.sql
  4. 증분 변경: migrations/00N_설명.sql
  5. 이 목록에 새 행 추가, 이전 버전 상태를 "이력"으로 변경
