v1.3.1 확정 정책

#항목결정

3이체 등록 화면✓ 고객명 확인/입력 + ✓ 입금할 본사 계좌번호 표시
4가상계좌 PG2차 개발 (MVP는 수동 납부확인)

01 · 계좌이체 레인 (확정)

고객 포털 — 결제 수단 선택 │ ├─ [카드 자동결제] → /payment/card │ └─ [계좌이체] → 이체 등록 화면 (승인 없이 즉시 완료) │ ├─ 표시: 본사 입금 계좌 (은행명 · 계좌번호 · 예금주) ├─ 입력: 입금자명 (기본값 = customers.name, 수정 가능) ├─ 동의: 매월 입금 안내 및 2일 유예 후 정지 정책 │ ▼ subscriptions.payment_method = 'manual' + depositor_name 저장 + bank_transfer_agreed_at 저장 │ ▼ 배포(go-live) 진행 가능

본사 입금 계좌 표시

  • 고객 화면에 이체할 계좌를 항상 보여줌 (복사 가능 UI 권장)
  • MVP 저장 위치: 환경변수 또는 설정 상수 (예: NEXT_PUBLIC_BANK_ACCOUNT)
  • 형식 예: 국민 123-456-789012 (주)마이플랫폼
  • 2차: 관리자 콘솔에서 계좌 정보 수정

02 · 미입금 · 정지 (manual, 2일)

시점동작
청구일 (next_billing_date)포털·(추후)이메일 입금 안내, billing_history unpaid 생성
+1일 ~ +2일미납 상태 유지, 방문자 사이트는 계속 운영 (유예)
+2일 경과billing_history.status = overdue, sites.status = suspended
납부 확인 후관리자 markBillingPaid → published 복구
next_billing_date (D-day) D+1 : unpaid (안내) D+2 : unpaid (마지막 유예) D+3 : overdue + sites.suspended ← 정책상 "2일 후" = 기한일 포함 2일 유예 후 3일째 정지 ※ 구현 시: due_at + INTERVAL '2 days' 로 계산
카드 레인: 미납·정지 규칙은 PG 연동 후 별도 정의 (v1.3.1 범위 밖).

  • 루트 A·B 모두 운영 개시 전 카드 or 계좌이체 고객 직접 선택
