02 · 결제 2레인

레인subscriptions.payment_method등록 시 고객 행위매월 3만원
A. 카드 자동 (기본) card 카드(빌링키) 등록 → customer_payment_methods 자동 청구 (handleProcessBilling)
B. 계좌이체 (예외) manual 「계좌이체」선택 + 입금자명·약관 동의 TBD: 관리자 승인 여부 입금 안내 → 관리자 납부 확인 (markBillingPaid)

03 · 루트 A (고객 직접 제작)

가입 → 템플릿/에디터 → 사이트 draft │ ▼ 결제 탭 또는 배포 버튼 │ ├─ [카드] ──► /payment/card → 빌링키 저장 │ └─ [계좌이체] ──► 이체 등록 화면 (입금자명·동의) [화면 TBD] │ ▼ deploySite() → published + subscriptions(trial, payment_method=card|manual) │ ▼ trial 14일 │ ├─ card → day14+ 자동 청구 (MOCK/PG) └─ manual → day14 입금 안내 → 관리자 납부확인 → active

04 · 루트 B (본사 대리 제작)

가입 → 제작 문의 (inquiries) │ ▼ 본사 견적 · 선금 50% (one_time_payments) │ ▼ 본사 제작 · 고객 검수용 미리보기 배포 ※ 구독 수단 불필요 (review 단계) │ (관리자 published, trial 없음 — 현재 코드와 유사) ▼ 잔금 50% (one_time_payments) — 개발비 정산 │ ▼ 고객 포털: 「서비스 시작」또는 「배포」 ← v1.3에서 명시 │ ├─ 카드 OR 계좌이체 선택 (루트 A와 동일 게이트) │ ▼ go-live → trial 14일 → 이후 월 구독 (레인 A or B)
현재 코드 갭: managed 사이트는 handleDeploy가 early return, 관리자 배포는 카드·이체 게이트 없음. v1.3 반영 시 고객 주도 go-live 단계 추가 필요.
