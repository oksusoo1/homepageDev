03루트 A self

/ → /login → /templates → /setup → /editor/{subdomain} → /my/{subdomain} "배포" 카드 없음 → /payment/card?redirect=deploy 카드 있음 → deploySite() → trial 시작 → /preview/{subdomain} 공개

04루트 B managed

문의(received) → 견적 → 선금(building) → 사이트 개설 → 관리자 배포(review, trial 없음) → 고객 미리보기 → 잔금(approved) → 카드+배포 → trial 시작 → done

05카드 등록 & 배포

카드 없이 배포 불가. lib/deploy.js — 최초 배포 시 trial 14일 + subscriptions 생성.

0614일 무료 체험

배포 day0: trial_started_at, trial_ends_at(+14일), status=trial day0~13: preview 이용, D-day 표시 day14 이전 해지: 결제 없음

07체험 종료 후 결제

day14: 관리자 "청구 처리" → 30,000원 → active → next_billing_date +1달 ※ 자동 Cron 미구현

08구독 해지 & 재구독

해지 예약: cancels_at까지 이용 가능. 만료 시 preview 방문 시 suspended. 재구독 시 즉시 결제 + published 복원.

09사이트 정지

관리자 정지 → sites=suspended, subscriptions=paused. 카드 미등록 draft는 preview 404.
