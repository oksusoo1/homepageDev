# 프로세스 2차 개선 — 2단계: 게시판 통합

문제: 게시판(`user_posts`)과 방문자 문의(`user_messages`)가 따로. 게시판을 여러 개 두거나 댓글·답변을 달 구조가 없음.
결정: **문의도 게시판의 한 종류** · 사장님 답변 = 댓글 · 고객 댓글은 고객 회원 기능 이후.

| 테이블 | 변경 |
|--------|------|
| `user_boards` (신규) | 사이트당 여러 게시판. `board_type` 이 동작 결정: notice(사장님만) · qna(연락처·비밀글·답변 필요) · general |
| `user_posts` | + `user_board_id` · `author_type`(owner/user) · `is_private` · `phone` · `email` · `updated_at` |
| `user_comments` (신규) | 댓글. 사장님 답변 = `author_type owner` |
| `user_messages` | **삭제** — `문의하기` 게시판 글 + 답변 댓글로 이관 |

- 마이그레이션: `docs/db/sql/migrations/022_user_boards.sql` · 덤프 `schema_v2.3_2026-09-22.sql`

- **답변 대기** = qna 게시판 · 고객 글 · 사장님 댓글 없음 (컬럼 없이 계산, `lib/user-board.js`)

화면
- 공개: `/s/{code}/board/{boardKey}` (목록·상세·작성). 상단 메뉴 = 게시판 순서대로. `/board` → 첫 게시판, `/contact` 삭제

- `/my` 사이트 카드: `답변 대기 N` 뱃지
