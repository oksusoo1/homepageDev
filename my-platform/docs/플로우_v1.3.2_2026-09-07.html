변경 요약
  • 공개 사이트(/s/{siteCode}) 문의 = 사용자→고객 (user_messages)
  • 수정요청(/my) = 고객→직원 (support_tickets) — 공개 메뉴에서 분리
  • 주체 용어: 고객 / 직원 / 사용자

1. 주체

용어DB설명
고객customers사장님 · 사이트 운영자
직원staff본사 · /platform
사용자(계정 없음)공개 사이트 방문자 · user_* 테이블

2. 공개 사이트 메뉴

/s/{siteCode} ├── 홈 → 사이트 본문 ├── 게시판 → user_posts └── 문의 → user_messages ← 사용자 → 고객 /s/{siteCode}/admin ← 고객 콘솔 (공개 메뉴에 없음) /my/{subdomain} ← 고객 포털 (수정요청 = support_tickets)

3. 문의·요청 3종

이름방향테이블경로
방문자 문의사용자 → 고객user_messages/s/.../contact
수정 요청고객 → 직원support_tickets/my/... 수정요청 탭
제작 의뢰고객 → 직원inquiries/my 본사 제작 문의

4. 사용자 문의 필드

이름* · 전화 · 이메일 · 내용* · 공개/비공개 · 고객 답글(reply_content)

상태: new → replied · UI: /s/.../contact + /my 방문자 문의 탭

5. 상태 리본

공개 사이트(/s/..., admin 제외)에서 sites.status가 review/draft/suspended/cancelled 이면 우측 상단 고정 리본 표시.
