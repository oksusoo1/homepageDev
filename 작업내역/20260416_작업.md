
## 2. 제작 문의(루트 B) DB 스키마 확장

### inquiries 테이블 필드 추가 (SQL + ERD)
```sql
ALTER TABLE inquiries
  ADD COLUMN IF NOT EXISTS dev_fee_total INTEGER,      -- 총 개발비
  ADD COLUMN IF NOT EXISTS down_paid_at TIMESTAMP,     -- 선금 50% 납부일
  ADD COLUMN IF NOT EXISTS final_paid_at TIMESTAMP;    -- 잔금 50% 납부일

-- status 확장
CHECK (status IN ('received','reviewing','building','review','approved','done'))
```

### status 흐름
```
received(접수) → reviewing(검토/견적) → building(제작중) → review(검수대기) → approved(잔금완료) → done(배포완료)
```
