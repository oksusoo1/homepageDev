## 4. 토스페이먼츠 개발자 계정 등록

### 4-1. 회원가입
1. https://developers.tosspayments.com 접속
2. 우측 상단 **"로그인"** → **"회원가입"** 클릭
3. 이메일 + 비밀번호 입력 후 가입 (사업자 없어도 개인으로 가입 가능)

### 4-2. 테스트 키 발급
1. 로그인 후 우측 상단 **"내 개발정보"** 클릭
2. **"API 키"** 탭 선택
3. 아래 두 가지 키 복사:
   - **클라이언트 키**: `test_ck_...` 로 시작 → 프론트엔드용
   - **시크릿 키**: `test_sk_...` 로 시작 → 서버(백엔드)용, 절대 노출 금지

### 4-3. .env.local 에 추가
프로젝트 루트 `.env.local` 파일에 아래 내용 추가:
```
NEXT_PUBLIC_TOSS_CLIENT_KEY=test_ck_복사한값
TOSS_SECRET_KEY=test_sk_복사한값
```
> ⚠️ `.env.local`은 Git에 커밋되지 않으므로 안전

### 4-4. 서버 재시작 (환경변수 적용)
```bash
# 기존 서버 Ctrl+C 로 종료 후
npm run dev
```

### 4-5. 개발 체험 상점의 한계
- 토스 개발자 계정의 **"개발 연동 체험 상점"** 은 데모용 MID
- **자동결제(빌링/정기결제)** 는 실제 사업자 등록 후 서비스 신청 필요
- 테스트 단계에서는 Mock 모드로 대체 (아래 참고)

### 4-6. 실제 서비스 전환 시 (나중에)
1. https://developers.tosspayments.com → **"전체상점 홈"**
2. **"결제 서비스 신청하기"** 클릭
3. 사업자등록증 등 서류 제출 → 심사 (수일 소요)
4. 승인 후 라이브 MID 발급 → `.env.local`에 라이브 키로 교체
5. `app/payment/card/page.js` 에서 `MOCK_MODE = false` 로 변경

## 5. 카드 등록 + 결제 플로우 구현

### 신규 생성 파일
| 파일 | 설명 |
|------|------|
| `app/payment/card/page.js` | 카드 등록 페이지 (구독 정보 표시 + 카드 입력 폼) |
| `app/payment/card/success/page.js` | 등록 완료 처리 페이지 |
| `app/payment/card/fail/page.js` | 등록 실패/취소 안내 페이지 |
| `app/api/payment/billing-auth/route.js` | 토스 빌링키 승인 서버 API |

### SDK 설치 방법
```bash
cd my-platform
npm install @tosspayments/payment-sdk
```
- 설치 버전: `@tosspayments/payment-sdk v1.9.2`
- 사용 위치: `app/payment/card/page.js` 에서 import
```js
import { loadTossPayments } from '@tosspayments/payment-sdk'
```

### 실제 토스 빌링 플로우 (MOCK_MODE = false 시)
```
1. 클라이언트: tossPayments.requestBillingAuth('카드', { customerKey, successUrl, failUrl })
2. 토스 결제창 오픈 → 고객이 카드 정보 입력
3. 토스가 successUrl로 리다이렉트 (authKey, customerKey 파라미터 포함)
4. 서버 API(/api/payment/billing-auth)에서 토스 서버로 빌링키 발급 요청
   POST https://api.tosspayments.com/v1/billing/authorizations/{authKey}
   Authorization: Basic Base64(시크릿키:)
5. 빌링키(pg_customer_id) 발급 → customer_payment_methods 테이블 저장
6. subscriptions.payment_method = 'card' 업데이트
```

### 테스트 모드 (Mock) — 현재 적용 중
- `app/payment/card/page.js` 상단에 `MOCK_MODE = true` 플래그
- 토스 팝업 없이 자체 카드 입력 폼으로 대체
- 등록 시 mock 빌링키(`MOCK_BILLING_{customer_id}_{timestamp}`) 생성
- `customer_payment_methods` + `subscriptions` 테이블 동일하게 저장
- `success?mock=true` 파라미터로 성공 페이지에서 API 호출 우회

```
⚠️ 실제 서비스 전환 시 변경사항:
app/payment/card/page.js → MOCK_MODE = false 로 변경만 하면 됨
나머지 코드(success/fail/API route)는 그대로 사용 가능
```
