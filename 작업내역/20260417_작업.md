draft 상태 사이트도 `/preview/{subdomain}` URL로 직접 접근 가능

// AS-IS

## 3. 사이트 삭제 기능 추가 (`app/platform/page.js`)

- draft 상태 + 구독 없는 사이트만 삭제 허용
- 삭제 전 confirm 다이얼로그
- 사이트 목록 각 행에 "삭제" 버튼 추가 (draft일 때만 표시)

```js
async function deleteSite(site) {
  if (site.status !== 'draft') { alert('draft만 삭제 가능'); return }
  if (!window.confirm(...)) return
  const { data: sub } = await supabase.from('subscriptions')...
  if (sub) { alert('구독 연결된 사이트는 삭제 불가'); return }
  await supabase.from('sites').delete().eq('site_id', site.site_id)
}
```

## 4. managed 사이트 trial 잘못 시작 버그 수정

### 문제
관리자가 managed 사이트 배포 시 `deploy_status`가 `pending`으로 남아 고객이 배포 버튼을 볼 수 있었고, 카드가 이미 있는 경우 trial이 잘못 시작됨

### 수정 1 — `updateSiteStatus` 구조 개선 (`app/platform/page.js`)
- build_type 조회를 status 업데이트 **이전**에 수행
- managed 배포 시: `deploy_status: 'live'`도 함께 업데이트
- managed / self 분기를 명확하게 if-else 처리

```js
// managed 배포
await supabase.from('sites').update({
  status: 'published',
  deploy_status: 'live',   // 추가
  updated_at: now.toISOString()
}).eq('site_id', siteId)
// inquiry → review (trial 없음)

// self 배포
await supabase.from('sites').update({
  status: 'published',
  updated_at: now.toISOString()
}).eq('site_id', siteId)
// pending 구독 있으면 trial 시작
```

## 5. 결제 흐름 재정의

### 확정 정책
```
배포 → 카드 등록 → 14일 무료체험 시작
  → 14일 내 취소: 결제 없음
  → 14일 경과: 관리자 "청구 처리" → 첫 결제(30,000원) → status: active
  → 이후 매월 자동 결제
```

### 수정 1 — `next_billing_date` 수정 (`lib/deploy.js`)
```js
// AS-IS: trial 종료 + 1달
const nextBilling = new Date(trialEnds)
nextBilling.setMonth(nextBilling.getMonth() + 1)
next_billing_date: nextBilling  // day 14 + 1달

// TO-BE: trial 종료일 = 첫 결제일
next_billing_date: trialEnds    // day 14
payment_method: 'card'          // 카드 필수 후 배포이므로
```

### 수정 2 — 즉시결제 제거 (`app/payment/card/page.js`)
- `redirect=deploy` 흐름: 즉시결제 없음 (trial 구독은 deploySite에서 생성)
- 재구독 흐름만 즉시결제 유지 (`note: '[MOCK] 재구독 즉시 결제'`)

### 수정 3 — "청구 처리" 버튼 추가 (`app/platform/page.js`)

## 6. 에디터 배포 카드 체크 누락 수정 (`app/editor/[subdomain]/page.js`)

### 문제
에디터에서 "배포" 버튼 클릭 시 카드 등록 없이 바로 배포됨

### 수정
- `customer` state 추가 및 `init()`에서 `setCustomer(cust)` 저장
- `handleDeploy` 최상단에 카드 체크 추가

```js
async function handleDeploy() {
  const { data: card } = await supabase
    .from('customer_payment_methods')
    .select('payment_method_id')
    .eq('customer_id', customer.customer_id)
    .eq('is_active', true)
    .maybeSingle()

  if (!card) {
    router.push(`/payment/card?site_id=${site.site_id}&redirect=deploy`)
    return
  }
  // 이후 기존 배포 로직
}
```
