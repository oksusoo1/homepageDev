# 2026-04-15 작업 내역

## 1. 구독 해지 데이터 모델 정리

### 상태별 컬럼 값 확정

| 상황 | status | cancelled_at | cancels_at | next_billing_date |
|------|--------|-------------|------------|-------------------|
| 정상 구독 | `active` | NULL | NULL | 날짜 |
| 해지 예약 | `active` | 요청일 | 종료예정일(미래) | NULL |
| 만료 처리됨 | `cancelled` | 요청일 | 종료일(과거) | NULL |
| 즉시 취소 | `cancelled` | 요청일 | NULL | NULL |

- `status`가 최종 판단 기준
- 해지 예약 판단: `status='active' && cancelled_at && cancels_at && cancels_at > now`
- `next_billing_date`는 해지 예약 시 `null`로 설정

### 해지 예약 시 next_billing_date null 처리 (`app/my/[subdomain]/page.js`)
```js
// AS-IS
.update({ cancelled_at: ..., cancels_at: ... })

// TO-BE
.update({ cancelled_at: ..., cancels_at: ..., next_billing_date: null })
```

## 2. cancels_at 만료 자동 처리 구현

### B안: 방문자 사이트 접속 시 자동 처리 (`app/preview/[domain]/page.js`)
- `getSite()` 함수에서 subscription의 `cancels_at` 체크
- `cancels_at < 오늘` + `status != 'cancelled'` → 자동 처리:
  - `subscriptions.status = 'cancelled'`
  - `sites.status = 'suspended'`
- 방문자에게 🔒 안내 페이지 표시

### C안: 관리자 콘솔 일괄 처리 버튼 (`app/platform/page.js`)
- 구독 현황 탭 우측 상단 **"만료 구독 처리"** 버튼 추가
- 쿼리 조건: `cancels_at < 오늘` + `status != 'cancelled'` + `cancels_at IS NOT NULL`
- 처리: 해당 구독 + 연결된 사이트 일괄 `cancelled`

## 3. 관리자 콘솔 구독 현황 테이블 개선 (`app/platform/page.js`)

### 컬럼 추가: 서비스 종료일
- `cancels_at` 값 있으면 날짜 표시 (빨간색)
- 없으면 `-` 표시

### 상태 배지 개선
- `active` → 초록색
- `trial` → 노란색 (기존엔 미구분)
- 그 외 → 회색

### 변경된 테이블 컬럼 순서
```
고객 | 사이트 | 월구독료 | 결제방식 | 다음청구일 | 상태 | 서비스 종료일 | 납부확인
```
